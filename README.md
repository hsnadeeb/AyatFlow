# Ayah Flow

A minimal Quran app built around one idea:

**Arabic recitation → English meaning → automatically continue to the next ayah.**

## V1 features

- 114 Surahs from Al Quran Cloud
- Uthmani Arabic
- Saheeh International English translation
- Mishary Alafasy verse audio
- Flow mode: Arabic recitation, then English device voice, then next ayah
- Playback speed: 0.75x / 1x / 1.25x / 1.5x / 2x
- English voice speed follows the selected flow speed
- Repeat current ayah
- Pause / resume / next / previous
- Continue from the last ayah
- Bookmark an ayah
- Dark/light appearance follows the device
- Background audio configuration for Android

## Important

Quran content and recitation are fetched from Al Quran Cloud's public API. The app does not bundle a copied Quran translation.

The V1 English "audio translation" is generated by the device's installed English speech engine using the displayed Saheeh International translation. This is intentionally simple and avoids bundling a separate English narrator.

## Run

```bash
npm install
npx expo install
npx expo start
```

For an Android APK:

```bash
npm install
npx expo prebuild --no-clean
npx eas build --platform android --profile preview
```

The project targets Expo SDK 57 / React Native 0.86.
